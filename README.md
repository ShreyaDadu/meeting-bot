\# Meeting Bot



A Google Meet automation bot built using Playwright.



\## Features Completed



\- Persistent Google Login

\- Automated Google Meet Joining

\- Automatic Microphone Muting

\- Automatic Camera Disabling

\- Browser Automation using Playwright



\## Current Status



Phase 1 completed:

\- Browser automation

\- Meeting auto join



Upcoming phases:

\- Audio recording

\- Whisper transcription

\- Meeting summaries



\## Tech Stack



\- Node.js

\- Playwright

\- Google Meet



\## Run



Install dependencies:



npm install



Run bot:



node scripts/working/join-meet-playwright.js
